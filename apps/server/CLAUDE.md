## Module Anatomy

Every feature module lives in `src/app/modules/<Name>/` and contains:

| File | Purpose |
|---|---|
| `<name>.interface.ts` | TypeScript interface / types |
| `<name>.model.ts` | Database model / schema |
| `<name>.validation.ts` | Request validation schemas |
| `<name>.service.ts` | Business logic (DB operations) |
| `<name>.controller.ts` | Request handlers (uses `catchAsync` + `sendResponse`) |
| `<name>.route.ts` | Express router |
| `<name>.constant.ts` | *(optional)* ENUMs, searchable fields |
| `<name>.utils.ts` | *(optional)* Module-specific helpers |

## Key Patterns

### Controller Pattern

```ts
import { Request, Response } from 'express';
import { catchAsync } from '../../utils/catchAsync';
import sendResponse from '../../utils/sendResponse';
import { StatusCodes } from 'http-status-codes';

const createItem = catchAsync(async (req: Request, res: Response) => {
  const result = await ItemService.create(req.body);
  sendResponse(res, {
    statusCode: StatusCodes.CREATED,
    success: true,
    message: 'Item created successfully',
    data: result,
  });
});
```

### Validation Pattern

```ts
// src/app/modules/Item/item.validation.ts
import { z } from 'zod';

const createItemSchema = z.object({
  body: z.object({
    name: z.string().min(1, 'Name is required'),
  }),
});
```

### Route Pattern

```ts
import express from 'express';
import { ItemControllers } from './item.controller';
import validateRequest from '../../utils/validateRequest';
import { ItemValidation } from './item.validation';
import auth from '../../middlewares/auth.middleware';

const router = express.Router();

router.post(
  '/,
  auth('USER'),
  validateRequest(ItemValidation.createItemSchema),
  ItemControllers.createItem,
);
router.get('/', auth('USER', 'ADMIN'), ItemControllers.getAllItems);

export const ItemRoutes = router;
```

## Authentication

This project uses JWT authentication with **HTTP-only cookie** token delivery.

### Protecting a Route

```ts
import auth from '../../middlewares/auth.middleware';

// Single role
router.get('/admin', auth('ADMIN'), controller.adminOnly);

// Multiple roles
router.get('/dashboard', auth('USER', 'ADMIN'), controller.dashboard);
```

## Critical Rules

- **Use CEM CLI** for scaffolding modules, middleware, and env vars — it handles file creation, naming, and route wiring automatically.
- **Never use `process.env` directly** — always import from `src/app/config`.
- **Middleware naming is enforced** — `<name>.middleware.ts` is mandatory. `cem build` rejects non-conforming files.
- **Do not remove inject markers** in `src/app/routes/index.ts` (`// --- INJECT IMPORTS HERE ---` and `// --- INJECT ROUTES HERE ---`).
- **Error handling is automatic** — the `globalErrorHandler` middleware maps mongoose and zod errors to a consistent `{ success, message, errorSources }` JSON response.
- **`catchAsync` is required** — all async Express handlers must be wrapped with it to avoid unhandled promise rejections.

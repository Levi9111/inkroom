## Architecture Rules

1. All source code lives under `src/`.
2. **Modules** follow domain-driven design: `src/app/modules/<Name>/` with files named `<name>.controller.ts`, `<name>.service.ts`, `<name>.route.ts`, `<name>.model.ts`, `<name>.interface.ts`, `<name>.validation.ts`.
3. **Middleware** files MUST be named `<name>.middleware.ts` inside `src/app/middlewares/`. The build will fail otherwise.
4. Routes are auto-registered in `src/app/routes/index.ts` via inject markers (`// --- INJECT IMPORTS HERE ---` and `// --- INJECT ROUTES HERE ---`). Do NOT remove these markers.
5. **All environment variables** go through `src/app/config/index.ts` — never use `process.env` directly in application code.
6. Wrap all async route handlers with `catchAsync()` from `src/app/utils/catchAsync.ts`.
7. Use `sendResponse()` from `src/app/utils/sendResponse.ts` for all API responses.
8. Use `validateRequest()` middleware to validate incoming request bodies against schemas.
9. Use `QueryBuilder` from `src/app/utils/QueryBuilder.ts` for search, filter, sort, and pagination on Mongoose queries.

## Model Pattern
